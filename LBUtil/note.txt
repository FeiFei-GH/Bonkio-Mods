Replay File Structure:
    File Name: "Description" + MapName + Timestamp

    Header Section (Unencrypted):
        Player Name
        Player Skin
        
        Map Name
        Map Data (compressed)
        
        Finish Time
        Player Positions per frame(30 FPS) (compressed)
        
        Timestamp
        Mod Version
        Game Version
        Digital Signature (Unlikely)

    Data Section (Encrypted):
        Input Data (compressed)

    Footer Section:
        Hash of Header Section
        Hash of Data Section

WorkFlow:
    Encrypt Data with asymetric key (code contains public key)
    Scure hash prevent collisions
    
    Valid initial state when game starts
